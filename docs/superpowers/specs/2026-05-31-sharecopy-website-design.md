# ShareCopy 官网设计文档

> 日期：2026-05-31 | 状态：已确认

## 概述

为 ShareCopy（跨平台局域网剪贴板共享与文件传输工具）构建一个 Apple 风格的产品官网。极简单页，纯静态 HTML/CSS，部署至 GitHub Pages。

## 设计方向

| 维度 | 决定 |
|------|------|
| 类型 | Apple 产品页风格极简单页 |
| 基调 | 极简白 + 大字体（白底、大量留白、SF 风格大标题） |
| 点缀色 | 科技紫 `#AF52DE`，渐变按钮 |
| 暗色模式 | 暂不支持（后续可加） |
| 技术栈 | 纯静态 HTML + CSS + 少量原生 JS，零框架 |

## 页面结构

## 各板块规格

### 1. 导航栏 Nav
- 固定在页面顶部，毛玻璃效果（`backdrop-filter: blur(20px)`）
- 左侧：ShareCopy Logo 文字
- 右侧：下载按钮（紫色填充，圆角）

### 2. Hero
- 大标题："跨设备，无缝共享"（48px+，font-weight: 800，letter-spacing: -1px）
- 副标题："在同一局域网内，实时同步剪贴板、快速传输文件"（灰色 #86868b）
- CTA 按钮："免费下载"，紫色渐变（#AF52DE → #5E5CE6），圆角 28px
- 可选：产品界面截图或示意图

### 3. 核心功能
- 3 张卡片水平排列（移动端垂直堆叠）
- 每张卡片：图标 + 标题 + 简短描述
- 卡片圆角 16px，浅灰背景，hover 时轻微上浮
- 功能：剪贴板实时同步、点对点文件传输、自动设备发现

### 4. 支持平台
- 三列图标 + 平台名
- macOS（Apple Silicon / Intel）、Windows（.msi）、Android（.apk）
- 每列下方带下载按钮或链接

### 5. 使用步骤
- 3 步水平排列，带序号圆圈
- ① 安装 ShareCopy → ② 同一 WiFi 下自动发现设备 → ③ 开始共享剪贴板和文件

### 6. Footer
- 简洁一行：GitHub 图标链接 + "© 2025 ShareCopy"
- 灰色小字

## 配色方案

| 用途 | 色值 |
|------|------|
| 背景 | `#ffffff` |
| 主文字 | `#1d1d1f`（Apple 风格近黑） |
| 次要文字 | `#86868b`（Apple 灰） |
| 点缀色 | `#AF52DE`（科技紫） |
| 点缀渐变 | `#AF52DE` → `#5E5CE6` |
| 卡片背景 | `#f5f5f7`（浅灰） |
| 分隔/边框 | `rgba(0,0,0,0.06)` |

## 字体

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text",
             "Helvetica Neue", Helvetica, Arial, sans-serif;
```

- 标题：font-weight 700–800
- 正文：font-weight 400–500
- 中文优先使用系统自带苹方

## 技术实现

### 文件结构
```
/
├── index.html          # 单页 HTML
├── style.css           # 所有样式
├── script.js           # 平滑滚动、hover 等微交互
├── favicon.png
└── assets/
    └── hero.png        # Hero 区域产品截图（可复用已有）
```

### 技术要求
- 纯静态，无构建工具
- 响应式布局：桌面（≥1024px）、平板（768–1023px）、手机（<768px）
- CSS 动画：卡片 hover、滚动渐显、按钮过渡
- 页面加载性能优先（无外部依赖，字体使用系统栈）
